Kullanim Kilavuzu

Dimmer: Ana ekrandaki dairesel alani dondurerek parlaklik ayarlayin.

Shutter: Panjur acikligini yuzde olarak kontrol edin.

Safe: Sifre kilidi ile cihazinizi koruyun.

Ayarlar: Alt bardaki disli ikonuna tiklayarak WiFi, guncelleme ve sistem ayarlarina erisin.

Developer Notlari

Mimari: ESP32 tabanli, dual-core islemci. FreeRTOS uzerinde async task yapisi.

Iletisim: WebSocket + SSE ile gercek zamanli veri akisi. REST API ile yapilandirma.

OTA: Firmware ve GUI icin ayri OTA kanallari. A/B slot destegi ile rollback imkani.

Depolama: NVS (Non-Volatile Storage) ile kalici ayarlar. Harici SPI flash uzerinde GUI dosyalari.
