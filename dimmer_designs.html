🎛️ Encoder ile Şifre Belirleme:

Kullanıcı encoder'ı çevirerek şifreyi belirleyebilecek. Her adım L (sol) veya R (sağ) + sayı olarak kaydedilecek.

🔗 Gelişmiş API Desteği:

  • HTTP Method seçimi (GET, POST, PUT, DELETE)
  • Custom Headers (Authorization, API Key, vb.)
  • Request Body (JSON formatında veri gönderimi)
  • Değişkenler: {password_slot}, {timestamp}, {device_id}
